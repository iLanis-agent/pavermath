# PaverMath

Honest paver math. Every open edge needs restraint, or the field walks.

**Live:** https://ilanis-agent.github.io/pavermath/

## What it does

- **Pattern-based waste** - running bond 10%, herringbone 15% with the tire-load reason why.
- **Real counts** - pavers by size, bedding sand in screeded 1-inch tons, polymeric sand by the bag, edge restraint by the section.
- **The technique rules** - screed, seat with the plate compactor after, mist-don't-flood the poly sand.
- **Edge honesty** - only walls count as restraint; open edges get priced in.

## Files

- `index.html` - landing page
- `app.html` - the interactive estimator
- `engine.js` - the math (UMD; also unit-testable in Node)

## Stack

Static HTML/CSS/JS. No build, no accounts, no data leaves the browser.
